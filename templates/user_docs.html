How to use FLUX

FLUX is the quiz and exam platform for creating timed assessments, taking quizzes, and reviewing performance. This guide covers the workflow for the {{ user.role|capitalize }} account you are signed in with.

Master capabilities

  • Create quizzes manually or import them from JSON.
  • Instantiate live quiz sessions for students.
  • Edit and delete quizzes from My Quizzes.

  • Review leaderboards and live arena standings.

Student capabilities

Create a quiz

  1. Sign in with a Master account.
  2. Choose Create New Quiz on the dashboard and enter the title, subject, and total duration.
  3. Add the first question, choose its type, enter the answer, points, and time limit, then add more questions as needed.
  4. Select Create Quiz to save it to your quiz list.

Create quickly with JSON

Prepare your questions in an LLM or editor, then open Create Quiz with JSON from the dashboard. Paste the JSON or upload a .json file, choose Validate and Preview, review the summary, and confirm creation.

{ "title": "Python Basics", "subject": "Python Programming", "duration_minutes": 30, "questions": [ { "type": "mcq", "text": "Which keyword is used to define a function in Python?", "answer": "def", "points": 1, "time_limit_seconds": 30, "options": ["function", "define", "def", "fun"] }, { "type": "tf", "text": "Python is a case-sensitive programming language.", "answer": "TRUE", "points": 1, "time_limit_seconds": 30 }, { "type": "short", "text": "What is the file extension used for Python files?", "answer": ".py", "points": 2, "time_limit_seconds": 45 } ] }

Your Student workflow

  1. Open Browse Quizzes from the dashboard.
  2. Select a quiz and read its subject, duration, and question count.
  3. Start the quiz and answer each question before its timer expires.
  4. Submit your answers to see your score, review results, and compare your performance on the leaderboard or podium.

Quiz JSON rules

Required fields: title, subject, duration_minutes, and questions.
Questions must contain between 1 and 50 items.
Allowed types are mcq, tf, and short.
Every question needs type, text, answer, points, and time_limit_seconds.
MCQs need at least two options, and the answer must exactly match one option.
True/false answers must be written as TRUE or FALSE.
Use duration_minutes for the full quiz and time_limit_seconds per question.
Send only valid JSON: no Markdown fences, comments, or extra text.
